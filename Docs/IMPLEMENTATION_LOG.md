It reserves leading evidence across segments, stores each selected passage's query index/text and local dense/lexical/RRF ranks in existing `review_evidence.retrieval_scores`, and keeps the diagnostic `_retrieve` two-value interface. Truncated plans, segments with no selected evidence, and findings marked `evidence_status:"insufficient"` cannot publish `coverage:"sufficient"`. The full immutable draft still supplies prompt text and code-point anchors. Regression tests cover late-segment contribution, shared passages, truncation, evidence-free segments and coverage downgrade.
